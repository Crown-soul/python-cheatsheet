## 已知的問題（保留原狀，當作之後的筆記素材）

- **`座標.py` 印錯座標**：`format(X1, X2)` 和 `format(Y1, Y2)` 把兩個點的 X 湊成一組、兩個 Y 湊成一組。實測 A(0,0)、B(3,4) 會印出「A點座標為(0.0,3.0)」「B點座標為(0.0,4.0)」。距離 5.0 算得對，錯的只有顯示。正確寫法是 `format(X1, Y1)` 和 `format(X2, Y2)`。
- **`bmi.py`、`溫度.py` 用 `eval( input(...) )`**：能跑，但 `eval` 會直接執行使用者打進來的任何字串。改用 `float( input(...) )` 比較安全，也是課堂後來的寫法。
- **`bmi.py` 的 `int(bmi)` 是無條件捨去**：170cm / 65kg 實際是 22.49，印出 22。要四捨五入用 `round()`。
- **`Class 01.py` 跟 `a = 1.py` 重複**：留著兩個是為了保留原樣，之後要刪哪個自己決定。
