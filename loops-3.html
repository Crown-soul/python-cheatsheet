def find_max ( S ):

同一個迴圈，三種包法

函式有沒有參數、有沒有 return，決定了它能不能被重複利用。

同樣是 1 加到 k 的迴圈，包成函式有三種寫法。三個印出來的數字一樣，但能做的事差很多：

3-7.py
def my_count1 ( ):
    t = 0
    for i in range( 1, k+1 ):
       t += i
    print ( t )


def my_count2 ( t ):
    for i in range( 1, k+1 ):
       t += i
    print ( t )


def my_count3 ( t ):
    for i in range( 1, k+1 ):
       t += i
    return  t


k = int( input( "enter :") )
total = 0

my_count1( )
my_count2( total )
print( my_count3( total ) )
輸出enter :5
15
15
15
  • my_count1沒有參數，自己準備 t = 0，算完直接印。只能印，結果拿不出來。
  • my_count2有參數，從外面接一個起始值進來，算完直接印。一樣拿不出來。
  • my_count3有參數，而且 return t 把答案交出來。這個才能拿去做別的事。
  • k三個函式都沒有把 k 當參數，是直接讀外面的 k。能跑，但函式就綁死在這個 k 上了。

差別在最後一行。my_count3 的結果可以存起來、可以再拿去算，另外兩個印完就沒了。

容易踩的坑
函式定義要寫在呼叫之前。把 my_count1( ) 搬到最上面，會噴 NameError: name 'my_count1' is not defined。Python 是從上往下讀的，還沒看到定義就叫不出來。
動手試
把 my_count3 的 return t 改成 print ( t )，再跑一次。這時候畫面會變成四行，猜猜多出來的第四行是什麼？

參數被蓋掉、忘記接回傳值，都不會報錯

函式裡重新寫 t = 0，傳進來的參數就沒被用到；函式 return 了但呼叫時沒接住，答案也一樣不見。

這兩個錯的共同點是程式照跑、不報錯、但答案是錯的。

錯的：參數被蓋掉
def my_sum ( t ):
    t = 0
    for i in range( 1, 6 ):
        t += i
    return t

print( my_sum( 100 ) )
輸出15
對的：用傳進來的 t
def my_sum ( t ):
    for i in range( 1, 6 ):
        t += i
    return t

print( my_sum( 100 ) )
輸出115

傳 100 進去卻印出 15，代表那個 100 完全沒被用到。第二個常見錯是有 return 卻沒接：

忘記接回傳值
def my_sum ( t ):
    for i in range( 1, 6 ):
        t += i
    return t

my_sum( 0 )
print( "結束" )
輸出結束
  • my_sum( 0 )算完了，答案也交出來了，但沒有人接。那個 15 就這樣消失。
  • 怎麼接寫成 A = my_sum( 0 ) 再 print( A )，或直接 print( my_sum( 0 ) )。
底下發生什麼事（想深入再點開）

沒有 return 的函式，Python 會替它回傳一個特別的值 None，意思是「沒有東西」。把它印出來就看得到：

none.py
def say_hi ( ):
    print( "hi" )

A = say_hi( )
print( A )
輸出hi
None

所以忘了寫 return，呼叫的地方拿到的是 None，不是答案。

容易踩的坑
有 return 的函式，單獨呼叫一行是完全不會有任何畫面的。看到「跑了但什麼都沒出現」，先檢查是不是忘了接回傳值或忘了 print。

找最大值：用 MAX 記住目前最大的，遇到更大的就換掉

準備 MAX 記住目前最大值、winI 記住它的編號，走一遍，遇到更大的就更新這兩個變數。

這是找最大值的標準作法。MAX 記住目前看過最大的數字，每拿到一個新的數字就跟它比，比較大就換成新的。

4-8-0.py
S = [ 100, 89, 5029, 6000 ]

i = 0
MAX = 0
winI = 0

for e in S:
    if ( e > MAX ):
        MAX = e
        winI = i
    i += 1

print( "最大編號 : ", winI )
print( "最 大 值 : ", MAX )
輸出最大編號 :  3
最 大 值 :  6000
  • MAX = 0一開始還沒看過任何數字，用 0 當起點。
  • winI = 0記住最大值是第幾個。要拿名字的時候會用到。
  • i += 1手動數現在走到第幾個。注意它縮在 for 底下、if 外面，因為每一輪都要加，不是換掉 MAX 時才加。
  • e > MAX比目前的 MAX 大才換。用 > 不是 >=，所以一樣大時不換。
容易踩的坑
把 i += 1 縮進 if 裡面（跟 winI = i 對齊），編號就會全錯，因為只有換掉 MAX 的那幾輪才數數。這個錯不報錯，只會算出奇怪的編號。下一個單元的 enumerate 可以讓這個坑消失。
之後能拿來做什麼
資料分析之後用 pandas 處理成績表，找出最大值跟它是誰各一行就做完。這段先認得形狀，路線圖第 13 站會教：
pandas_max.py
import pandas as pd

score = pd.Series( [ 100, 89, 29, 60 ], index=[ "apollo", "vickey", "pig", "elsa" ] )
print( score.idxmax(), score.max() )
輸出apollo 100
動手試
把 S 改成 [ 6000, 100, 89 ]（最大的放第一個），確認編號印出 0。

enumerate：編號跟東西一起拿

enumerate 會同時給你「第幾個」和「是什麼」，不用自己維護 i += 1。

上一個單元用了三行來管編號（i = 0、i += 1、還要注意縮排）。enumerate 把這件事包好了：

4-9.py
def find_max2 ( S ):
    MAX = 0
    winI = 0

    for(i, e) in enumerate( S ):
        if ( e > MAX ):
            MAX = e
            winI = i

    return winI


score = [ 100, 89, 29, 60 ]
print( find_max2( score ) )
輸出0

它實際產生的東西長這樣，每一份都是「編號, 東西」成對出現：

9.py
name = [ "apollo", "vickey", "pig" ]

print( list( enumerate( name ) ) )
print( list( enumerate( name, 1 ) ) )
輸出[(0, 'apollo'), (1, 'vickey'), (2, 'pig')]
[(1, 'apollo'), (2, 'vickey'), (3, 'pig')]
  • (i, e)一次接兩個值。i 是編號，e 是東西。括號可加可不加。
  • enumerate( S, 1 )第二個參數是編號從幾開始。預設 0，想從 1 開始就寫 1。
  • 少了三行i = 0 不用了、i += 1 不用了、縮排放錯的風險也沒了。

要講清楚一件事：enumerate 沒有比較快。一百萬筆資料實測，手動數 25.2 毫秒、enumerate 25.5 毫秒，幾乎一樣。它的好處是少寫三行、少一個會出錯的地方，不是速度。

容易踩的坑
輸入的編號通常從 1 開始（使用者習慣），程式的編號從 0 開始。enumerate( S, 1 ) 可以讓顯示的編號從 1 起跳，但這時候 i 就不能直接拿去當 name[i] 的索引了，會差一格。顯示用和取值用要分清楚。
動手試
把 find_max2 的 enumerate( S ) 改成 enumerate( S, 1 )，猜猜印出來的編號會變成多少？

同一題的另外兩種寫法：max + index、zip

max 找值、index 找位置，一行就找到最大值的編號；zip 把名字跟分數扣成一組，一次拿到人跟分數。

找最大值還有兩種寫法。邏輯跟單元 21 一樣，差別是把一部分工作交給 Python 內建的工具。

寫法一：max( S ) 找值，S.index() 找位置
find_max4.py
def find_max4( S ):
    winI = S.index( max( S ) )
    return winI

score = [ 100, 89, 29, 60 ]
print( max( score ) )
print( find_max4( score ) )
輸出100
0
  • max( S )內建函式，回傳 S 裡最大的值，這裡是 100。
  • S.index( 100 )問 S「100 在第幾格」，回傳 0。
  • 由內往外讀先算 max( S ) 得到 100，再把 100 交給 S.index()。

中間那個 . 的意思是「用 S 自己身上的功能」。max() 是內建函式，什麼都能丟進去，所以寫 max( S )；index 是 list 自帶的方法，要寫成 S.index( 100 )，寫 index( S, 100 ) 會出錯。

寫法二：zip 把兩排資料一對一扣起來

zip 把 name 跟 score 同一格的東西配成一組 tuple，跟拉鍊左右兩排扣在一起一樣：

zip.py
name = [ "apollo", "vickey", "pig", "elsa" ]
score = [ 100, 89, 29, 60 ]

print( list( zip( name, score ) ) )
輸出[('apollo', 100), ('vickey', 89), ('pig', 29), ('elsa', 60)]

拿這些配對去找最大值，記住的就不是編號，而是整組「名字, 分數」：

find_max5.py
def find_max5( N, S ):
    MAX = 0
    win = ( "", 0 )

    for e in zip( N, S ):
        if ( e[1] > MAX ):
            MAX = e[1]
            win = e
    return win


name = [ "apollo", "vickey", "pig", "elsa" ]
score = [ 100, 89, 29, 60 ]
win = find_max5( name, score )
print( win )
print( "第一名：%s  分數； %d" % ( win[0], win[1] ) )
輸出('apollo', 100)
第一名：apollo  分數； 100
  • e[1]每一組的第 1 格是分數，拿它來比。e[0] 是名字。
  • win = e跟單元 21 的 winI = i 同一個位置，記住的是整組，不是編號。
  • win = ( "", 0 )起點先放一組空名字、0 分，形狀跟之後要放進來的一樣。

三種寫法回傳的東西不一樣，拿到之後要做的事也不一樣：

  • 單元 21、22回傳編號 0，還要再寫 name[0]、score[0] 去查。
  • max + index一樣回傳編號，程式只剩一行。
  • zip直接回傳 ('apollo', 100)，名字和分數一起拿到。
容易踩的坑
zip 用到的兩個清單都要從參數傳進來。課堂版寫 def find_max5( S )，裡面卻用到 N，跑起來會出現 NameError: name 'N' is not defined。改成 def find_max5( N, S )，呼叫時寫 find_max5( name, score )。
課堂版把變數取名叫 max。同一個函式裡如果還要呼叫 max( S )，會出現 TypeError: 'int' object is not callable，因為 max 已經被換成數字 0 了。所以上面改用 MAX。
動手試
先猜 find_max4( [ 70, 95, 95 ] ) 會回傳 1 還是 2，再跑跑看。有兩個一樣大的時候，.index() 回傳的是哪一個？

為什麼一定要包成函式：i 會被蓋掉

找最大值的迴圈如果直接寫在主程式，裡面的 i 會把使用者輸入的編號蓋掉，程式直接出錯。

迴圈（一）的單元 07 說過迴圈變數會留著。現在看它實際出錯的樣子。假設使用者輸入 2，想查第 2 個人：

10.py
name = [ "apollo", "vickey", "pig", "elsa" ]
score = [ 100, 89, 29, 60 ]

i = 2 - 1

MAX = 0
winI = 0
i = 0
for e in score:
    if ( e > MAX ):
        MAX = e
        winI = i
    i += 1

print( name[i] )
輸出Traceback (most recent call last):
  File "10.py", line 16, in <module>
    print( name[i] )
          ~~~~^^^
IndexError: list index out of range
  • i = 2 - 1使用者要查第 2 個人，i 應該是 1（vickey）。
  • i = 0 ... i += 1找最大值的迴圈把 i 當計數器用，跑完變成 4。
  • name[4]名單只有 0 到 3，所以 IndexError。

把找最大值的迴圈包成 find_max 函式就沒事了，因為函式裡的 i 是函式自己的，外面的 i 碰不到。這就是課堂檔案 4-8.py 要包成函式的理由，不是為了「看起來整齊」。

底下發生什麼事（想深入再點開）

在函式裡指定的變數，只存在函式裡面。函式外面有一個同名的變數，也不會被影響，兩個是不同的變數：

local.py
def find ( ):
    i = 99
    print( "函式裡的 i：", i )

i = 1
find( )
print( "外面的 i：", i )
輸出函式裡的 i： 99
外面的 i： 1

所以把找最大值的迴圈包進函式，裡面的 i 怎麼變，都碰不到外面使用者輸入的 i。

容易踩的坑
這種錯有時候更難發現：如果名單剛好夠長，不會 IndexError，只會默默查到別人的資料。所以不要靠「有沒有報錯」判斷程式對不對。
動手試
把上面找最大值的迴圈搬進一個 def find_max( S ): 裡面，確認最後印出的是 vickey。

MAX = 0 遇到全負數就會錯

MAX 從 0 開始，比 0 小的數字永遠換不上去。全部是負數時，答案會是錯的。

分數不會是負的，所以課堂範例沒問題。但換成溫度、盈虧這種會有負數的資料就會出事：

11.py
def find_max ( S ):
    MAX = 0
    winI = 0
    for( i, e ) in enumerate( S ):
        if ( e > MAX ):
            MAX = e
            winI = i
    return winI

print( find_max( [ -5, -2, -9 ] ) )
print( find_max( [ 7, 7, 3 ] ) )
輸出0
0
  • [ -5, -2, -9 ]正確答案是編號 1（-2 最大），但印出 0。因為沒有一個數字大於 0，MAX 從頭到尾沒換過。
  • [ 7, 7, 3 ]兩個 7 平手，印出 0＝第一個。因為條件是 > 不是 >=。想取最後一個平手的，改成 >=。

正確的作法是拿第一個元素當 MAX 的起點，而不是 0：

修好的版本
def find_max ( S ):
    MAX = S[0]
    winI = 0
    for( i, e ) in enumerate( S ):
        if ( e > MAX ):
            MAX = e
            winI = i
    return winI

print( find_max( [ -5, -2, -9 ] ) )
輸出1
容易踩的坑
這個改法有個前提：清單不能是空的，不然 S[0] 會 IndexError。Python 有內建的 max() 已經處理好這些狀況，實測也快兩倍。先自己寫一遍，才知道它在做什麼。
動手試
用修好的版本跑 [ 0, 0 ]，確認印出 0；再跑 [ -1 ]，確認印出 0。

四個清單並排，用同一個編號串起來

name[i]、score[i]、live[i] 用的是同一個 i，所以同一個編號在四個清單裡指的是同一個人。

這是整份筆記的綜合應用。四個清單長度一樣、順序一樣，第 0 個都是 apollo 的資料：

2-4-1.py
name = [ "apollo", "vickey", "pig", "elsa" ]
score = [ 100, 89, 29, 60 ]
live = [ True, True, False, True ]
level = [ "good", "ok", "so..", "bad" ]

i = int( input( "請輸入 index :" ) ) - 1

if ( i < 0 ):
    print( "索引不能小於 1" )
elif ( i > 3 ):
    print( "索引不能大於 4" )
else:
    if ( live[i] == False ):
        print ( "學生已經退學" )
    else:
        if ( score[i] == 100 ):
            print( "%s 分數：%d ，程度：%s" % (name[i], score[i], level[0]) )
        elif ( score[i] > 60 ):
            print( "%s 分數：%d ，程度：%s" % (name[i], score[i], level[1]) )
        elif ( score[i] == 60 ):
            print( "%s 分數：%d ，程度：%s" % (name[i], score[i], level[2]) )
        else:
            print( "%s 分數：%d ，程度：%s" % (name[i], score[i], level[3]) )
輸出輸入 1 → apollo 分數：100 ，程度：good
輸入 2 → vickey 分數：89 ，程度：ok
輸入 3 → 學生已經退學
輸入 4 → elsa 分數：60 ，程度：so..
輸入 0 → 索引不能小於 1
輸入 5 → 索引不能大於 4
  • - 1使用者從 1 開始數，程式從 0 開始數，所以要減 1。
  • i < 0輸入 0 會變成 -1。Python 的 -1 是合法索引（指最後一個），不擋的話會查到 elsa 的資料。
  • i > 3輸入 5 會變成 4，超出名單範圍。
  • 先擋再查兩個檢查都通過才進 else 去查資料。先做主程式、再補防呆，但防呆一定要補。
容易踩的坑
陣列索引 -1 在 Python 不會報錯，它指的是最後一個。所以 i < 0 這個檢查不能省。省了不會當掉，只會查錯人。

少一個 else，退學的人會被印兩次

退學就不該再印分數。用 if 接著 if，兩段都會執行；要用 else 才擋得住。

課堂檔案有兩個版本，差別只有一個 else。先看有問題的那版（2-4.py、4-8.py 都是這樣寫的）：

2-4.py（有問題）
if ( live[i] == False ):
    print ( "學生已經退學" )

if ( score[i] == 100 ):
    print( "..." )
elif ( score[i] > 60 ):
    print( "..." )
輸出輸入 3 → 學生已經退學
輸入 3 → pig 分數：29 ，程度：bad
（兩行都印出來了）
2-4-1.py（修好的）
if ( live[i] == False ):
    print ( "學生已經退學" )
else:
    if ( score[i] == 100 ):
        print( "..." )
    elif ( score[i] > 60 ):
        print( "..." )
輸出輸入 3 → 學生已經退學
（只有這一行）
  • 兩個獨立的 if各自判斷，互不相干。退學印完了，分數那段還是會照跑。
  • if / else只會走其中一邊。退學了就不進去看分數。
容易踩的坑
判斷「兩個結果會不會同時成立」是關鍵：如果是同一件事的不同答案（退學 vs 正常顯示），用 if / else；如果是兩件各自獨立的事（及格了 vs 全勤獎），才用兩個分開的 if。這裡是前者。

跑完什麼都沒印三種可能：函式有 return 但沒人接、函式定義好了卻沒有呼叫、print 縮排放錯位置跑到不會執行的地方。

怎麼讀錯誤訊息

錯誤訊息照這三步讀：

實際的錯誤訊息
Traceback (most recent call last):
  File "4-8.py", line 3, in <module>
    print( name[i] )
           ~~~~^^^
IndexError: list index out of range
  • 先看最後一行那是結論。IndexError: list index out of range 就是「編號超出名單範圍」。
  • 再看 line N它直接告訴你第幾行出事。跳過去看那一行，不用從頭找。
  • 中間可以跳過Traceback、檔案路徑、那排 ~~~~^^^ 是指出問題在哪個位置，讀的時候可以先跳過。

常見的錯誤訊息

IndentationError冒號下一行忘了縮排，或縮排的空格數不一致（混用 Tab 和空白）。
IndexError編號超過清單範圍。常見於迴圈變數把外面同名的變數蓋掉（單元 24）。
NameError函式或變數還沒定義就拿來用。函式定義要放在呼叫之前。
TypeError: 'int' object is not callable把變數取名叫 max，之後又想呼叫 max()。內建函式被數字蓋掉了（單元 23）。
KeyboardInterrupt不是錯誤，是你按了 Ctrl + C。

找錯改錯：最大值的編號不對

這段程式要找出最大值跟它的編號。最大值 90 找對了，編號卻印成 2，但 90 在清單裡是第 3 個（從 0 開始數）。找出錯在哪裡並改好。

max_index.py
S = [ 5, 80, 3, 90 ]

i = 0
MAX = 0
winI = 0

for e in S:
    if ( e > MAX ):
        MAX = e
        winI = i
        i += 1

print( "最大編號 : ", winI )
print( "最 大 值 : ", MAX )
