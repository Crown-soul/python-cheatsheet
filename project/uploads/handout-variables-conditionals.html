01

變數是什麼

變數就像幫記憶體裡的一份資料取個名字，之後要用這份資料，直接呼叫名字就好。用 = 把右邊的值存進左邊的變數名稱；同一個變數之後可以重新賦值，新值會蓋掉舊值。

範例程式
1-1.py
a = 1
b = 2
c = a + 1

print( a, b, c )
02

常數的命名慣例

Python 沒有真正「禁止修改」的常數語法。大家的慣例是把不打算再更動的值，用全大寫命名，提醒自己（跟合作的人）這個值不要去動它。

範例程式
參考範例
# 全大寫 = 這是慣例上的常數，不要去改它
TAX_RATE = 0.05
MAX_SCORE = 100

price = 500
print( price * (1 + TAX_RATE) )
03

變數命名規則

  • 只能用字母、數字、底線 _，而且不能用數字開頭
  • 大小寫是不同的變數（大小寫敏感）
  • 不能用 Python 保留字（像 if、for、class）當變數名稱
  • 建議用蛇式命名法：單字全小寫，中間用底線連接，例如 student_name
範例程式
參考範例
student_name = "小美"
Student_Name = "阿明"

print( student_name )
print( Student_Name )

# 3name = "錯誤示範"   -> SyntaxError，不能用數字開頭
# if = 10              -> SyntaxError，if 是保留字
04

賦值 = 與比較 ==

一個等號 = 是「動作」，把右邊的值存進左邊的變數。兩個等號 == 是「提問」，問左右兩邊是不是相等，結果只會是 True 或 False，通常寫在 if 後面。如果 if 後面不小心只打一個 =，Python 會直接噴出語法錯誤。

範例程式
範例
a = 100

if int(a) == 100:
    print("good !")
05

使用者輸入與型別轉換

input() 不管你輸入什麼，回傳的一定是字串（str）。要拿來做數學運算，得先用 int() 或 float() 轉型，不然會跟數字型態衝突而報錯。

範例程式
1-1.py
a = 1
b = 2
c = a + 1

print( a, b, c )

d = input( "pls enter:" )
print( d )

DD = int( d )
e = c + DD

print( e )
06

條件判斷 if / elif / else

if / elif / else 由上往下依序檢查，符合哪一個條件就執行哪一段，其餘全部跳過。

範例程式
untitled0.py
a = input("plz enter")
print(a)

if ( int(a) == 100 ):
    print("SooooooooooGoooooooood")
elif ( int(a) >= 80 ):
    print("GoooooooD Job")
elif ( int(a) >= 60 ):
    print("Nice")
else:
    print("what???")

這裡用「由高到低」的順序判斷（100 → 80 → 60）。elif 的順序很重要，如果順序排錯，後面的條件可能永遠不會被檢查到。

07

and / or 邏輯運算子

and 要兩邊條件都成立才是 True；or 只要有一邊成立就是 True。可以把多個判斷式包在一起，組成更複雜的條件。

範例程式
參考範例
score = int(input("分數："))
attend = int(input("出席次數："))

# and：分數及格「而且」出席次數達標，兩個都要成立
if score >= 60 and attend >= 10:
    print("通過")

# or：分數很高「或者」全勤，只要有一個成立就好
if score >= 90 or attend >= 15:
    print("加分認定")

這裡刻意把 and、or 分成兩段獨立的 if，避免混在同一串 if / elif 裡互相影響、變得不好判斷。

08

字串與數字不能直接相加

Python 規定字串跟數字不能直接用 + 加在一起：數字加數字是數學加法；字串加字串是把兩段文字接起來；但字串加數字會直接噴出 TypeError。

範例程式
參考範例
print( 1 + 2 )        # 3　(數字加數字)
print( "1" + "2" )    # "12" (字串接字串)
print( "1" + 2 )      # TypeError，字串不能直接加數字

處理原則：要拼到畫面上顯示 → 全部換成字串；要做數學計算 → 全部換成數字。

09

f-string 格式化字串（推薦寫法）

老師這週示範是用舊式的 %s / %d 寫法組字串。現在更推薦用 f-string：字串前面加 f，變數直接寫在 {} 裡面，Python 會自動幫你轉成字串，不用再手動轉型或接一堆 + 號。

範例程式（舊式寫法）
2-3-0.py
A1 = "apollo"
A2 = "ava"
a2 = 99

print( "%s %s 好 %d" % (A1, A2, a2) )
print( A1 + " 好" )
範例程式（f-string 寫法）
改寫版本
print( f"{A1} {A2} 好 {a2}" )
print( f"{A1} 好" )
