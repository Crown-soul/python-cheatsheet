最容易記錯的一個
終端機是 ⌃ `（Control），不是 ⌘ `。VS Code 裡少數幾個在 Mac 上還是用 Control 的快捷鍵之一。
程式跑不動的時候

這幾個都不是程式寫錯，是執行環境的操作問題。卡在這種地方最浪費時間，因為畫面上看起來完全沒有線索。

按了 Run Cell，input() 的提示沒出現，畫面像沒反應
用 # %% 跑 cell 的時候，輸入框會跳在編輯器最上方，跟指令面板同一個位置，不在下面的 Interactive 面板。很多人盯著下面等，沒注意到上面已經跳出來了。
往螢幕最上方看，在那個小框打字再按 Enter。
一直跳出 KeyboardInterrupt
有東西按了 Ctrl+C。程式本身不會產生這個錯誤。在終端機裡 Ctrl+C 永遠是「中斷正在跑的程式」，跟 Windows 的複製不一樣。
想複製終端機的文字：選取之後按 ⌘C，不要按 Ctrl。
程式停住不動，游標在閃
它在等你輸入，這是 input() 正常的行為，不是當掉。
打字，按 Enter。
錯誤訊息怎麼看

從最後一行看起，再回頭找行號。不用從頭讀。

一個真的錯誤訊息長這樣 
Traceback (most recent call last):
  File "/Users/你/Desktop/python/demo.py", line 2, in <module>
    total = score + 5
            ~~~~~~^~~
TypeError: can only concatenate str (not "int") to str
01 先看最後一行。它告訴你錯誤類型（TypeError）跟原因（字串只能接字串，不能接數字）。
02 line 2 就是出事的行號。直接跳到第 2 行，不用整份從頭看。
03 底下那排 ~~~~^~~ 是在指「這一段出問題」，^ 對準的位置就是重點。
04 中間那幾行是程式怎麼一層一層走到出錯的地方，剛開始學可以先跳過。
SyntaxError語法寫錯：漏冒號、漏括號、if 後面只打一個 =。
TypeError型別不合：字串和數字相加，或拿字串去跟數字比大小。
ValueError型別對但內容不能轉：int("八")。
NameError用到還沒定義的變數，或名字打錯字、大小寫不一致。
IndentationError縮排不對：if 下一行忘了縮進去，或空格數不一致。
KeyboardInterrupt不是程式的錯，是有人按了 Ctrl+C 把它中斷掉。
筆記記錄
2026-09-15 # %% 的用途：在 .py 檔裡把程式切成一格一格，上方會出現 Run Cell，點了只跑那一格，變數留在互動視窗裡，效果跟 Jupyter Notebook 一樣。
2026-09-20 f-string 不會擋型別錯誤：忘記轉型，f"{age}" 照樣印得出來；舊式的 %d 反而會噴 TypeError，等於幫你抓到忘記轉型。
2026-09-20 小數有誤差是正常的：0.1 + 0.2 印出來是 0.30000000000000004。要顯示乾淨一點用 f"{值:.2f}" 指定小數位數。
