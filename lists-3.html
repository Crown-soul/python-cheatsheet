先看一列放什麼：score[人][科]

二維串列先看「一列放什麼」。這份一列放一個人，所以 score[1][2] 是第 2 個人的第 3 科。

課堂上同一份成績寫過兩種樣子。5-18.py 用三個清單，一個清單是一科；7-24.py 改成一個大串列，裡面每個小串列是一個人。用 zip 把三科並排拿出來，每一輪拿到的剛好是一個人的三科，跟 score 的每一列一樣。

two_ways.py
score1 = [100, 89, 59, 60]
score2 = [100, 99, 69, 65]
score3 = [100, 100, 59, 70]

for person in zip(score1, score2, score3):
    print(person)

score = [[100, 100, 100], [89, 99, 100], [59, 69, 59], [60, 65, 70]]
print(score[1])
print(score[1][2])
print(score1[1])
輸出(100, 100, 100) (89, 99, 100) (59, 69, 59) (60, 65, 70) [89, 99, 100] 100 89
  • zip(score1, score2, score3)每一輪從三個清單各拿同一格，拿到的是同一個人的三科。印出來四行，就是 score 的四列。
  • score[1]第 2 個人那一整列。
  • score[1][2]先拿第 2 個人，再拿他的第 3 科。前面的編號是人，後面的是科。
  • score1[1]舊的排法：第 1 科裡的第 2 個人。同一個 89，兩種排法取的方式不一樣。
底下發生什麼事（想深入再點開）

zip 每一輪給的是元組，所以印出來是小括號。用 list() 把它整個裝起來，看得到四個元組。反過來，zip(*score) 會把一人一列轉回一科一條（課堂沒教，先認得形狀，星號的意思是把 score 的四列拆開分別交給 zip）：

zip_inside.py
score1 = [100, 89, 59, 60]
score2 = [100, 99, 69, 65]
score3 = [100, 100, 59, 70]
score = [[100, 100, 100], [89, 99, 100], [59, 69, 59], [60, 65, 70]]
pairs = list(zip(score1, score2, score3))
print(pairs)
print(type(pairs[0]))
print(list(zip(*score)))
輸出[(100, 100, 100), (89, 99, 100), (59, 69, 59), (60, 65, 70)] <class 'tuple'> [(100, 89, 59, 60), (100, 99, 69, 65), (100, 100, 59, 70)]

一份表格不管怎麼存，資料都一樣。差別在第一個編號拿到的是「一個人」還是「一科」，這要看建立串列的時候怎麼排。

容易踩的坑
編號順序寫反。score 有 4 個人、每人 3 科，寫成 score[0][3]（想拿第 4 個人的第 1 科）會跳 IndexError: list index out of range，因為每個人只有第 0、1、2 科。看到 IndexError，先回頭確認這份串列一列放的是什麼。
之後能拿來做什麼
資料分析CSV 檔一列是一筆資料（一個人、一天、一筆訂單），用 Python 讀進來就是一人一列的二維串列。路線圖第 13 站的 pandas 表格也是同一個方向。

換成一人一列，函式少傳三個參數

資料改成一人一列，函式只要收名字跟成績兩個參數，一個人的三科用 sum(row) 一次加完。

課堂的 5-18.py 跟 7-24.py 跑出來的畫面一模一樣，差在資料的排法跟函式收幾個參數。下面拿「找最高分」這個函式對照，兩段都回傳 (名字, 總分)：

find_max_old.py
def find_max(N, S1, S2, S3):
    MAX = 0
    win = ""
    for e in zip(N, S1, S2, S3):
        t = e[1] + e[2] + e[3]
        if t > MAX:
            MAX = t
            win = e[0]
    return win, MAX

name = ["apollo", "vickey", "pig", "elsa"]
score1 = [100, 89, 59, 60]
score2 = [100, 99, 69, 65]
score3 = [100, 100, 59, 70]
print(find_max(name, score1, score2, score3))
輸出('apollo', 300)
find_max_new.py（推薦）
def find_max(N, S):
    MAX = 0
    win = ""
    for i, row in enumerate(S):
        t = sum(row)
        if t > MAX:
            MAX = t
            win = N[i]
    return win, MAX

name = ["apollo", "vickey", "pig", "elsa"]
score = [[100, 100, 100], [89, 99, 100], [59, 69, 59], [60, 65, 70]]
print(find_max(name, score))
輸出('apollo', 300)
  • zip(N, S1, S2, S3)舊寫法要把四個清單並排，e[0] 是名字，e[1] 到 e[3] 是三科。
  • enumerate(S)新寫法一次拿一列，i 是第幾個人，row 是他的三科。名字用 N[i] 去拿。
  • sum(row)一列裡有幾科就加幾科，不用寫 e[1] + e[2] + e[3]。

enumerate 在串列（下）單元 15、找最大值的寫法在迴圈（三）單元 21，這裡只換了資料的排法。

動手試
在 score 每一列後面加第 4 科（例如 [100, 100, 100, 90]），新寫法的函式要改幾個地方？舊寫法要改幾個地方？兩邊都改改看。

開箱拿出一列，推導式拿出一欄

for x, y, z in score 每一輪把一列拆成三個變數。推導式前面寫 y 拿到整欄，寫 x + y + z 拿到每列的總和。

unpack_rows.py
score = [[100, 100, 100], [89, 99, 100], [59, 69, 59], [60, 65, 70]]

for x, y, z in score:
    print(x, y, z)

second = [y for x, y, z in score]
print(second)

totals = [x + y + z for x, y, z in score]
print(totals)
輸出100 100 100 89 99 100 59 69 59 60 65 70 [100, 99, 69, 65] [300, 288, 187, 195]
  • for x, y, z in score每一輪拿出一列，再照順序拆給 x、y、z。開箱在串列（下）單元 13。
  • [y for x, y, z in score]每一列只留中間那個，四個人的第 2 科排成一串。
  • [x + y + z for ...]每一列三個加起來，四個人各一個總分。

開箱要先知道一列剛好有幾個。不想數的話，用編號拿也可以，一列有幾科都能用：

column.py
score = [[100, 100, 100], [89, 99, 100], [59, 69, 59], [60, 65, 70]]
second = [row[1] for row in score]
print(second)
輸出[100, 99, 69, 65]

名字跟成績分成兩個串列的時候，用 zip(name, score) 並排。每一輪拿到的是「名字」跟「一整列」：

name_and_row.py
name = ["apollo", "vickey", "pig", "elsa"]
score = [[100, 100, 100], [89, 99, 100], [59, 69, 59], [60, 65, 70]]
for n, row in zip(name, score):
    print(n, row, sum(row))
輸出apollo [100, 100, 100] 300 vickey [89, 99, 100] 288 pig [59, 69, 59] 187 elsa [60, 65, 70] 195
容易踩的坑
有一列的長度不一樣，開箱就會出錯。最後一列多一科 [60, 65, 70, 80]，前三列照常印出來，到第四列跳 ValueError: too many values to unpack (expected 3)；少一科則是 not enough values to unpack。每列長度不固定時，改用 row[1]、sum(row)。
之後能拿來做什麼
資料分析拿出一欄算平均是最常做的統計，例如「全班第 2 科平均」。pandas 寫成 df["第2科"].mean()，先認得形狀，路線圖第 13 站會教。

一列印在同一行：end 跟 %2d

內層迴圈用 end 不換行，%2d 讓每個數字佔兩格，內層跑完再印結尾跟換行。

課堂的 6-20-2.py 把乘法表的每一列印成加法算式，最後接上總和。這裡只印前三列：

row_sum.py
for i in range(1, 4):
    t = 0
    for j in range(1, 10):
        k = i * j
        t += k
        print("%2d" % k, end=("+" if j != 9 else " "))
    print("= %d" % t)
輸出 1+ 2+ 3+ 4+ 5+ 6+ 7+ 8+ 9 = 45 2+ 4+ 6+ 8+10+12+14+16+18 = 90 3+ 6+ 9+12+15+18+21+24+27 = 135
  • "%2d" % k數字至少佔兩格，只有一位數的前面補一個空白，上下才對得齊。
  • end=("+" if j != 9 else " ")不是第 9 個就接 +，第 9 個接空白。這種寫在一行裡的 if else 跟串列（下）單元 18 推導式前面那種是同一個東西。
  • print("= %d" % t)沒寫 end，印完會換行，下一列從新的一行開始。

end 第一次出現在串列（上）單元 09。%2d 只補空白、不砍數字，數字比寬度長就照原樣印：

width.py
print("%d|" % 5)
print("%2d|" % 5)
print("%2d|" % 45)
print("%2d|" % 100)
輸出5| 5| 45| 100|

%d 遇到小數會直接捨去，不會四捨五入。算平均要留小數，用 %.1f（留到小數點後一位，95.666… 印成 95.7）：

avg_format.py
avg = 287 / 3
print(avg)
print("%d" % avg)
print("%.1f" % avg)
輸出95.66666666666667 95 95.7
容易踩的坑
想空一行寫成 print("\n")，會空兩行。print 印完自己會再換一次行，所以 \n 加上這一次是兩行。只要換行，寫 print()；課堂寫的 print(end="\n") 跟 print() 一樣。
blank_line.py
print("A")
print("\n")
print("B")
print()
print("C")
輸出A B C

怎麼讀錯誤訊息

錯誤訊息照這三步讀：

實際的錯誤訊息
Traceback (most recent call last):
  File "index_order.py", line 2, in <module>
    print(score[0][3])
          ~~~~~~~~^^^
IndexError: list index out of range
  • 先看最後一行那是結論。IndexError: list index out of range 就是「編號超出範圍」。
  • 再看 line N它直接告訴你第幾行出事。跳過去看那一行，不用從頭找。
  • 中間可以跳過Traceback、檔案路徑、那排 ^^^ 是指出問題在哪個位置，讀的時候可以先跳過。這裡 ^^^ 指在 [3] 底下，就是第二個編號超出範圍。

常見的錯誤訊息

IndexError: list index out of range編號超出範圍。二維串列先確認一列放什麼，再確認兩個編號的順序（單元 19）。
ValueError: too many values to unpack (expected 3)開箱的變數比那一列的元素少，某一列多了一格（單元 21）。
ValueError: not enough values to unpack (expected 3, got 2)開箱的變數比那一列的元素多，某一列少了一格（單元 21）。

寫完自己檢查一遍

這四個問題都是這份筆記跟課堂範例裡實際出現過的坑。寫完程式從頭問一遍。

一列放什麼這份串列一列是一個人還是一科？兩個編號的順序有沒有照它寫？（單元 19）
每列一樣長嗎用開箱之前，每一列的元素數量都一樣嗎？不一樣就改用編號或 sum(row)。（單元 21）

名詞小辭典

二維串列
串列裡面每一格又是一個串列，像一張表格。score[1][2] 用兩個編號拿值。
列 / 欄
列是橫的一行（這份是一個人），欄是直的一排（這份是一科）。
轉置
把列跟欄對調。zip(*score) 可以做到，課堂沒教。
條件運算式
A if 條件 else B，寫在一行裡的 if else，條件成立給 A，不成立給 B。

找錯改錯：多一個人，總平均就錯了

課堂範例算全班總平均的時候寫了 Tavg/4。下面這段照同樣的寫法，資料多加了第 5 個人。程式跑得出結果，但結果不對，找出錯在哪裡並改好。

avg.py
def class_avg(S):
    total = 0
    for row in S:
        total += sum(row) / 3
    return total / 4

score = [[100, 100, 100], [89, 99, 100], [59, 69, 59], [60, 65, 70], [80, 80, 80]]
print("總平均：%.1f" % class_avg(score))
現在跑出來總平均：100.8
預期輸出總平均：80.7
