01

用中括號把一串資料包起來

用中括號 [ ] 把資料包起來、中間用逗號隔開，就是一個串列；len() 算出裡面有幾個。

迴圈（一）的單元 02 已經用 for 把「清單」裡的東西一個一個拿出來，那個清單就是這裡的串列（list），同一個東西。這一份從頭把串列本身能做的事補齊：放進去、拿出來、找、加、刪、排順序。

串列（list）裡的每一個資料叫做元素。同一個串列可以放不同型別，像 info 同時放了字串、整數、小數。空的串列寫成 []，長度是 0。

list_basic.py
scores = [90, 75, 60, 88]
names = ["小明", "小華", "小美"]
info = ["小明", 18, 170.5]
empty = []

print(scores)
print(info)
print(len(scores))
print(len(names))
print(len(empty))
輸出[90, 75, 60, 88]
['小明', 18, 170.5]
4
3
0
  • len(scores)回傳串列裡有幾個元素。scores 有 4 個分數，所以是 4。
  • print(scores)整個串列印出來會帶著中括號跟逗號，字串會加上單引號。
容易踩的坑
元素之間的逗號要用半形的 ,。中文輸入法沒切回來，打成全形的 ，，會跳 SyntaxError: invalid character '，' (U+FF0C)。訊息裡的 U+FF0C 就是全形逗號的編號。
02

用編號拿出某一格，也用編號改掉它

串列[編號] 拿出某一格，編號從 0 開始；-1 是最後一格。串列[編號] = 新的值，就把那一格換掉。

編號（索引，index）寫在串列名稱後面的中括號裡。第一個是 0，第二個是 1。倒過來數用負數：-1 是最後一個，-2 是倒數第二個。

  • names[-1]不用知道串列有多長就拿得到最後一個。串列之後變長變短，-1 一樣指向最後一個。

編號代表「從第一格往後走幾格」。第一格自己就在開頭，往後走 0 格，所以編號是 0。4 個元素的串列，最後一格要往後走 3 格，編號是 len(names) - 1，所以是 3。

負的編號是 Python 幫你做了一次換算：names[-k] 會被當成 names[len(names) - k]，所以 names[-1] 就是 names[len(names) - 1]。下面三行印出來可以對照：

print(names[len(names) - 1])
print(names[-1])

03

找東西：in、.index()、.count()

in 問「在不在」，回答 True 或 False；.index() 問「在第幾格」；.count() 問「出現幾次」。

三個都是用來找東西的，差在回答的形式。in 的結果是布林值，可以直接放在 if 後面；.index() 回傳編號；.count() 回傳次數，找不到就是 0。

find.py
fruits = ["蘋果", "香蕉", "芭樂", "香蕉"]

print("香蕉" in fruits)
print("西瓜" in fruits)
print("西瓜" not in fruits)

print(fruits.index("香蕉"))
print(fruits.count("香蕉"))
print(fruits.count("西瓜"))
輸出True
False
True
1
2
0
  • fruits.index("香蕉")串列裡有兩個香蕉（第 1 格跟第 3 格），.index() 只回傳第一個找到的位置，所以是 1。
  • "西瓜" not in fruitsnot in 是反過來問「是不是不在」。不在，所以是 True。

迴圈（三）的單元 23 用過 max() 加 .index() 找最高分的人，用的就是這裡的 .index()。

容易踩的坑
.index() 找不到東西會直接報錯，跳 ValueError: '西瓜' is not in list。不確定在不在的時候，先用 in 問過再拿編號：
find_safe.py
fruits = ["蘋果", "香蕉", "芭樂", "香蕉"]
target = "西瓜"

if target in fruits:
    print(target, "在第", fruits.index(target), "格")
else:
    print("沒有", target)
輸出沒有 西瓜
04

加東西：append、extend、insert

append 把一個東西加到最後面；extend 把另一個串列的東西全部接到後面；insert(位置, 東西) 插到指定的編號。

三個方法都寫成 串列.方法(...)，加完之後原本的串列就變了，不用再存回去。

add.py
cart = ["牛奶"]

cart.append("麵包")
print(cart)

cart.extend(["雞蛋", "蘋果"])
print(cart)

cart.insert(0, "衛生紙")
print(cart)
輸出['牛奶', '麵包']
['牛奶', '麵包', '雞蛋', '蘋果']
['衛生紙', '牛奶', '麵包', '雞蛋', '蘋果']
  • cart.insert(0, "衛生紙")插到第 0 格，原本的東西全部往後挪一格。
  • cart.extend([...])括號裡放的是另一個串列，裡面的元素一個一個接到後面。
容易踩的坑
想一次加兩個，卻用了 append，整個串列會變成一格：
append_list.py
cart = ["牛奶"]
cart.append(["雞蛋", "蘋果"])
print(cart)
print(len(cart))
輸出['牛奶', ['雞蛋', '蘋果']]
2

長度是 2 不是 3。一次加好幾個要用 extend。

容易踩的坑
寫成 cart = cart.append("麵包")，cart 會變成 None，整個購物清單不見了：
append_none.py
cart = ["牛奶"]
cart = cart.append("麵包")
print(cart)
輸出None
底下發生什麼事（想深入再點開）

append、extend、insert 都是直接改掉原本那個串列，改完之後回傳 None（Python 用來表示「什麼都沒有」的值）。把回傳值印出來就看得到：

append_return.py
cart = ["牛奶"]
result = cart.append("麵包")
print(result)
print(cart)
輸出None
['牛奶', '麵包']

所以 cart = cart.append(...) 是先把麵包加進去，再把回傳的 None 存回 cart，原本的串列就找不回來了。之後再寫 cart.append(...) 會跳 AttributeError，因為 None 沒有 append 這個方法。

之後能拿來做什麼
資料分析讀檔案的時候先準備一個空串列，每讀到一列就 append 一筆，全部讀完再算平均或排序。檔案處理在路線圖第 9 站。
小工具一直問使用者要加什麼，打一個就 append 一個。這份的小專案就是這樣做。
05

刪東西：pop、remove、clear

pop() 拿走最後一個，pop(編號) 拿走那一格，兩種都會把拿走的東西回傳給你；remove(東西) 刪掉第一個符合的；clear() 全部清空。

差別在你手上有什麼：知道編號用 pop，知道內容用 remove。pop 會回傳被拿走的那個，可以用變數接住再拿去用；remove 跟 clear 回傳 None。

remove.py
cart = ["衛生紙", "麵包", "牛奶", "麵包", "雞蛋"]

last = cart.pop()
print(last)
print(cart)

first = cart.pop(0)
print(first)
print(cart)

cart.remove("麵包")
print(cart)

cart.clear()
print(cart)
輸出雞蛋
['衛生紙', '麵包', '牛奶', '麵包']
衛生紙
['麵包', '牛奶', '麵包']
['牛奶', '麵包']
[]
  • cart.pop()括號空著，拿走最後一個（雞蛋），存進 last。
  • cart.remove("麵包")串列裡有兩個麵包，只刪掉前面那個，後面的還在。
容易踩的坑
remove 要刪的東西不在串列裡，會跳 ValueError: list.remove(x): x not in list。對空的串列 pop() 會跳 IndexError: pop from empty list。跟單元 03 一樣，不確定在不在就先用 in 問。
動手試
把 cart 裡的麵包全部刪掉，不是只刪第一個。提示：while 的條件可以寫成 "麵包" in cart（while 在迴圈（二）單元 17）。
06

for 走過一個串列時，不要邊走邊刪同一個串列

用 for 走過串列時，在迴圈裡 remove 同一個串列，元素可能被跳過、沒檢查到；要篩選就把要留下的 append 到另一個新串列。

目標是把不及格（小於 60）的分數刪掉，應該剩下 [90]。下面這段程式跑得完、不會報錯，但結果不對：

remove_in_loop.py
scores = [50, 40, 90, 30]

for s in scores:
    if s < 60:
        scores.remove(s)

print(scores)
輸出[40, 90]

40 也不及格，卻沒被刪掉。換個做法，不動原本的串列，把要留的收集到新串列：

keep_passed.py
scores = [50, 40, 90, 30]
passed = []

for s in scores:
    if s >= 60:
        passed.append(s)

print(passed)
輸出[90]
底下發生什麼事（想深入再點開）

for 是照編號一格一格往下走：第一輪拿第 0 格，第二輪拿第 1 格。刪掉第 0 格的 50 之後，後面的元素全部往前挪一格，40 移到了第 0 格。第二輪去拿第 1 格，拿到的是 90，40 就被跳過了。在迴圈裡把每一輪的狀態印出來：

remove_trace.py
scores = [50, 40, 90, 30]

for s in scores:
    print("拿到", s, "時，串列是", scores)
    if s < 60:
        scores.remove(s)
輸出拿到 50 時，串列是 [50, 40, 90, 30]
拿到 90 時，串列是 [40, 90, 30]
拿到 30 時，串列是 [40, 90, 30]

整理成表格：

輪拿第幾格拿到這一輪結束時的串列
1050[40, 90, 30]
2190[40, 90, 30]
3230[40, 90]

第三輪拿完第 2 格之後，串列只剩兩格，沒有第 3 格可以拿，迴圈就結束了。40 從頭到尾都沒被拿出來檢查過。

容易踩的坑
這種錯不會跳錯誤訊息，程式照樣跑完，但結果少刪了。分數剛好沒有兩個不及格連在一起的時候，結果還會是對的，所以測試資料要放「兩個不及格相鄰」的情況才抓得到。

07

排順序：sorted() 給你新的，.sort() 改掉原本的

sorted(串列) 排好一份新的串列交給你，原本的不動；串列.sort() 直接把原本的串列排好；加上 reverse=True 就是由大到小。

兩個都是由小到大排。要不要保留原本的順序，決定用哪一個：還要用原本的順序就用 sorted()，不需要了就用 .sort()。.reverse() 是把順序整個倒過來，不會比大小。

sort.py
scores = [75, 90, 60, 88]

print(sorted(scores))
print(sorted(scores, reverse=True))
print(scores)

scores.sort()
print(scores)

names = ["小明", "小華", "小美"]
names.reverse()
print(names)
輸出[60, 75, 88, 90]
[90, 88, 75, 60]
[75, 90, 60, 88]
[60, 75, 88, 90]
['小美', '小華', '小明']
  • print(scores)第三個 print：sorted() 用過兩次，scores 的順序沒變。
  • scores.sort()這行之後 scores 本身變了。它跟單元 04 的 append 一樣回傳 None，不要寫成 scores = scores.sort()。
  • names.reverse()小明、小華、小美倒過來變成小美、小華、小明，跟名字的大小無關。
容易踩的坑
用 input() 收進來的分數是字串，字串是一個字一個字比的，"100" 的第一個字 1 比 "9" 的 9 小，所以會排在前面：
sort_str.py
scores = ["9", "10", "100", "25"]
print(sorted(scores))
輸出['10', '100', '25', '9']

存進串列之前先用 int() 轉成數字，排出來才會是 9、10、25、100。

之後能拿來做什麼
資料分析做排行榜：sorted(分數, reverse=True) 排好，再用下一個單元的切片取前三名。
08

切片：用 [開始:結束] 切出一段

串列[開始:結束] 切出一段新的串列，包含開始那一格、不包含結束那一格；第三個數字是間隔。

規則跟迴圈（一）單元 04 的 range(開始, 結束, 間隔) 一樣：包含開始、不包含結束，間隔給負數就倒著走。間隔是正的時候，開始不寫代表從頭，結束不寫代表到底；間隔是負的時候反過來，開始不寫代表從最後一格開始。

102030405060
正的編號012345
負的編號-6-5-4-3-2-1
slice.py
nums = [10, 20, 30, 40, 50, 60]

print(nums[1:4])
print(nums[:3])
print(nums[3:])
print(nums[-2:])
print(nums[::2])
print(nums[::-1])
輸出[20, 30, 40]
[10, 20, 30]
[40, 50, 60]
[50, 60]
[10, 30, 50]
[60, 50, 40, 30, 20, 10]
  • nums[1:4]拿第 1、2、3 格，第 4 格不拿。
  • nums[:3]從頭拿到第 2 格，剛好是前 3 個。
  • nums[-2:]從倒數第二格拿到底，就是最後兩個。
  • nums[::-1]間隔 -1，開始不寫就從最後一格開始，一路倒著拿到第一格。

切片切出來的是新的串列，原本的 nums 不會變。

容易踩的坑
用編號拿 nums[100] 會跳 IndexError（單元 02），切片的範圍超出串列卻不會報錯，只會切出存在的那幾格，一格都沒有就是空串列：
slice_out.py
nums = [10, 20, 30, 40, 50, 60]
print(nums[4:100])
print(nums[100:])
輸出[50, 60]
[]

所以切片寫錯範圍時程式照樣跑，要自己看結果對不對。

之後能拿來做什麼
資料分析排行榜取前三名：先由大到小排，再切前三個。
top3.py
scores = [72, 95, 88, 60, 99, 81]
top3 = sorted(scores, reverse=True)[:3]
print(top3)
輸出[99, 95, 88]
動手試
用切片拿出 nums 裡編號是奇數的那幾格（20、40、60）。

09

串列裡再放串列：用兩個中括號拿

串列的每一格也可以是一個串列；拿裡面的東西用兩個中括號，第一個選哪一排，第二個選那一排的第幾個。

座位表有三排、每排三個人，可以寫成「三個串列放在一個大串列裡」。seats[1] 拿到的是第 1 排整排（一個串列），後面再接 [2] 就是從那一排拿第 2 個。一行寫太長的話，可以像下面這樣每一排換一行，Python 看到中括號還沒關起來，會繼續讀下一行。

seats.py
seats = [
    ["小明", "小華", "小美"],
    ["阿強", "阿珍", "阿偉"],

程式好像卡住了怎麼辦

小專案跟練習 3 會用到 input()。下面幾種狀況看起來像程式壞了，但都不是程式寫錯：

畫面沒反應，游標在閃程式跑到 input() 在等你打字。直接輸入，再按 Enter。用 VS Code 的 Run Cell（# %%）時，輸入框會跳在編輯器最上方，不在下面的終端機，很容易找不到。
KeyboardInterrupt有人按了 Ctrl + C。最常見的原因是想複製終端機的文字，結果按成中斷鍵（複製要用 ⌘C）。
一直問、停不下來while True 要靠 break 才出得去。檢查輸入的字跟 if 比對的字一不一樣，例如程式寫「離開」，你打成「離開 」多一個空白，就永遠對不上。要強制停下來就按 Ctrl + C。

怎麼讀錯誤訊息

錯誤訊息照這三步讀：

實際的錯誤訊息
Traceback (most recent call last):
  File "index_error.py", line 2, in <module>
    print(names[4])
          ~~~~~^^^
IndexError: list index out of range
  • 先看最後一行那是結論。IndexError: list index out of range 就是「編號超出串列的範圍」。
  • 再看 line N它直接告訴你第幾行出事。跳過去看那一行，不用從頭找。
  • 中間可以跳過Traceback、檔案路徑、那排 ^^^^ 是指出問題在哪個位置，讀的時候可以先跳過。

常見的錯誤訊息

IndexError編號超過串列範圍。最後一格是「長度減 1」（單元 02）；巢狀串列兩個編號都要減 1（單元 09）。
ValueError.index() 或 .remove() 要找的東西不在串列裡（單元 03、05）。先用 in 問。
SyntaxError: invalid character程式裡混進全形符號，最常見的是全形逗號（單元 01）。
AttributeError: 'NoneType' object has no attribute 'append'前面寫了 cart = cart.append(...)，cart 已經變成 None（單元 04）。
TypeError: 'NoneType' object is not subscriptable寫了 scores = scores.sort()，再拿 scores[-1] 就會這樣（單元 07）。

最後一格的編號用的是長度減 1，或直接寫 -1？（單元 02）

名詞小辭典

串列 / list
用中括號包起來、照順序排的一串資料，可以加、刪、改。
元素
串列裡的每一個資料。
索引 / index
元素在串列裡的編號，從 0 開始數；負數從最後面倒著數。
方法
接在某個值後面、用點呼叫的函式，例如串列的 append、sort。它作用在點前面的那個值上。
切片 / slice
[開始:結束:間隔]，切出一段新的串列，不含結束那一格。
None
Python 表示「什麼都沒有」的值。append、sort 這類直接改掉原本串列的方法，回傳的就是它；pop 例外，會回傳拿走的東西。

小專案

購物清單

出門前一直想到要買什麼，這個程式讓你隨時加進去、買到了就刪掉、隨時看還剩什麼。一步一步來，每一步都先跑得起來再做下一步：

01準備一個空串列 cart = []，用 while True 一直問「要做什麼（加／刪／看／離開）」。while 後面寫 True，條件永遠成立，迴圈只能靠 break 離開。先只做「離開」：輸入離開就 break，迴圈外面印出最後的清單。
02做「加」：再問一次品名，用 append 加進去，印出「已加入 品名」。
03「加」的時候，品名已經在清單裡就印「品名 已經在清單裡了」，不重複加。
04做「刪」：問品名，在清單裡就刪掉並印「已刪除 品名」，不在就印「清單裡沒有 品名」。程式不能報錯。
05做「看」：先印共幾項，再一行一個印出清單，編號從 1 開始。
提示
刪之前不先問在不在，remove 找不到會跳 ValueError（單元 03、05）。
break 在迴圈（二）單元 16，while 在單元 17。
編號從 1 開始：可以用 enumerate 的第二個參數，也可以印 i + 1（迴圈（三）單元 22）。
