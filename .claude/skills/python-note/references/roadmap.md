# Python 學習路線圖

這份是路線圖的**資料來源**：節點順序、每個節點對應哪一堂課、目前狀態，都以這裡為準。目錄頁 `index.html` 的「學習路線圖」區塊是照這張表畫出來的，**改了這裡就要同步改 `index.html`**，反過來也一樣。

## 使用者的目標（決定路線怎麼排）

- 還在上課，**主線照課程走**：課堂教到哪，筆記就做到哪。
- 還不確定之後要用 Python 做什麼，所以先打好基礎跟底層邏輯。
- 之後的方向優先順序：**資料分析 > 小工具 > 網頁 API**。
- 路線圖是「建議的學習順序」，依照觀念的依賴關係排，**不是上課順序**。每個節點標出對應的課堂，上課順序跟路線圖順序不同時，筆記還是照上課進度做，做完在路線圖上點亮對應節點就好。

## 節點狀態（四種）

| 狀態 | 意思 | 判斷方式 |
|---|---|---|
| 已完成 | 筆記做好了 | 根目錄有對應的 `.html` |
| 待做 | 課堂教過，筆記還沒做 | 對照上表日期，今天已經過了那堂課 |
| 還沒上 | 課堂還沒教到 | 日期還沒到 |
| 自學補 | 課程不教，要自己補 | 上表找不到這個主題；主線改用 pythonbook.cc 對應章節（見 `source-material.md`「課程不教的節點」） |

跨章專案（P 站）不跟課堂走，只有兩種狀態：「還沒做」「已完成」。

每次做新筆記前，先對照今天日期更新一次狀態（「還沒上」→「待做」）。
