## v3 — 2026-09-20：補上環境卡關、批改流程、練習題可驗證性

起因：使用者反映筆記只教語法，沒教「程式怎麼跑不起來」，而這才是卡最久的地方；另外筆記完成後大量發生「學生貼程式碼問對不對」的情境，需要固定流程。

- 附錄新增兩個條件式必加區塊：「程式好像卡住了怎麼辦」（input() 存在就要加）、「怎麼讀錯誤訊息」。
- 練習題規則新增「預期輸出」：不給答案，但給可驗證的輸入輸出組合，讓學生不用問人也能自己核對。
- 題目敘述新增「單位跟邊界要寫死」規則。
- 新增整段「批改學生貼上來的程式碼」流程：先看題目要求 → 實際執行不要用讀的 → 測試結果列表格 → 問題分三級（會當掉／邏輯錯／風格不符）→ 每個問題指回筆記單元編號。

## v2 — 2026-09-20：練習題、原始教材整理、自我審查修正

- 新增練習題跟大魔王題的規則跟 HTML 模板。
- 新增「原始教材是雜亂筆記時先整理再寫」流程：全部讀完列清單 → 判斷依賴鏈畫章節 → 合併重複 → 抓出容易出錯的段落 → 新舊寫法對照 → 練習題從依賴鏈自然長出來；教材量大時先給大綱確認。
- 自我審查修正 and/or 規則：原本只教「混用要加括號」，補上「先判斷兩個結果會不會同時成立，會的話要拆成兩個獨立的 if，不能用 elif」。
- 放寬「先問清楚」的適用範圍：只有新建筆記或大幅擴充才要先問，局部修改直接做。
