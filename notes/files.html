01

os 模組與目前資料夾

import os 之後，os.getcwd() 會告訴你程式現在所在的資料夾，只寫檔名不寫路徑時，Python 就從這個資料夾找起。

os 是 Python 內建的模組，裝好 Python 就有，不用另外安裝。它提供一組跟作業系統溝通的函式：查檔案、建資料夾、刪檔案都在裡面。程式執行的時候有一個「目前工作資料夾」。像 "a.txt" 這樣只寫名字的叫相對路徑，從目前工作資料夾找起；從磁碟最上層一路寫到檔案的叫絕對路徑。

demo.py
import os

print(os.getcwd())
print(os.path.abspath("a.txt"))
輸出/Users/你/Desktop/demo /Users/你/Desktop/demo/a.txt
  • import os把 os 模組拿進程式，之後用 os.函式名() 呼叫裡面的函式。
  • os.getcwd()回傳目前工作資料夾的完整路徑。名稱是 get current working directory 的縮寫。
  • os.path.abspath()把相對路徑接上目前工作資料夾，變成絕對路徑。檔案不存在也能算。
底下發生什麼事（想深入再點開）

目前工作資料夾跟 .py 檔放在哪裡沒有關係，它是你執行指令時所在的資料夾。同一支 where.py，從兩個不同的資料夾執行，印出來的位置就不同：

終端機
$ cd ~/Desktop/demo
$ python3 where.py
/Users/你/Desktop/demo
$ cd ~/Desktop
$ python3 demo/where.py
/Users/你/Desktop
容易踩的坑
程式說找不到檔案，但檔案明明在旁邊，先在第一行加 print(os.getcwd())。印出來的就是這次執行實際使用的資料夾，不是你以為的那一個，是這類問題最常見的原因。
02

檢查檔案或資料夾在不在

os.path.exists(名稱) 回傳 True 或 False，檔案和資料夾都適用，動手之前先問它一次。

刪檔案、建資料夾、改名這些動作，碰到「已經存在」或「根本不存在」都可能報錯。先用 exists 問清楚，再用 if 決定要做什麼。

demo.py
import os

print(os.path.exists("a.txt"))
print(os.path.exists("sub"))
print(os.path.exists("missing.txt"))

if os.path.exists("a.txt"):
    print("a.txt 在")
else:
    print("a.txt 不在")
輸出True True False a.txt 在
  • exists只回答在不在，不分檔案或資料夾。要分辨用下一個單元的 isfile 和 isdir。
  • 回傳值是 True 或 False，可以直接放在 if 後面當條件。
容易踩的坑
exists 回傳 False，但你覺得檔案在，常見原因有三個。第一，目前工作資料夾不是你以為的那個（單元 01）。第二，檔名拼錯，包含大小寫跟副檔名。第三，Windows 檔案總管預設隱藏已知的副檔名，畫面上的 copyfile.txt 實際檔名可能是 copyfile.txt.txt。不確定的時候用下一個單元的 os.listdir() 印出實際的名字。
動手試
在 demo.py 旁邊建一個 test 資料夾，再執行一次，看 os.path.exists("test") 印出什麼。
03

列出資料夾裡有什麼

os.listdir(路徑) 回傳這個資料夾裡所有名字組成的串列，順序不固定，要排序就自己加 sorted()。

"." 代表目前工作資料夾。下面的資料夾裡有 a.txt、b.txt、c.py、一個叫 sub 的資料夾（裡面有 inner.txt），還有一個隱藏檔 .hidden。第一行是 listdir 直接回傳的順序，每台電腦、每個資料夾可能不一樣；第二行排序之後，到哪裡執行都一樣。

demo.py
import os

print(os.listdir("."))
print(sorted(os.listdir(".")))
輸出['.hidden', 'b.txt', 'sub', 'a.txt', 'c.py'] ['.hidden', 'a.txt', 'b.txt', 'c.py', 'sub']

要知道每個名字是檔案還是資料夾，用 os.path.isfile() 或 os.path.isdir()。要挑出特定副檔名，用字串的 endswith() 檢查名字是不是以 ".txt" 結尾。字串方法在路線圖第 6 站會完整教，這裡先認得形狀。

demo.py
import os

for name in sorted(os.listdir(".")):
    if os.path.isfile(name):
        print(name, "是檔案")
    else:
        print(name, "是資料夾")

txt_files = [name for name in sorted(os.listdir(".")) if name.endswith(".txt")]
print(txt_files)
輸出.hidden 是檔案 a.txt 是檔案 b.txt 是檔案 c.py 是檔案 sub 是資料夾 ['a.txt', 'b.txt']
  • isfile(名字)是檔案回傳 True。資料夾回傳 False。isdir() 剛好相反。
  • endswith(".txt")名字最後面是 .txt 回傳 True。
  • 推導式[name for name in ... if ...] 是串列（下）教過的寫法：一行做完走訪加篩選。
容易踩的坑
listdir 回傳的只有名字，沒有路徑。拿去複製或改名時要用 os.path.join() 接上資料夾（單元 07）。它也不會進到子資料夾：上面 sub 裡的 inner.txt 沒有出現在結果裡。名字開頭是 . 的隱藏檔會被列出來，輸出裡的 .hidden 就是。Mac 的 Finder 在資料夾裡建立的 .DS_Store 也屬於這一類。
之後能拿來做什麼
資料分析一個資料夾裡每個月一份銷售 CSV，用 listdir 挑出所有 .csv，再一份一份讀進來合併。
小工具列出下載資料夾，依副檔名分類，這個做法在小專案會用到。
apply3.py
import os

csv_files = [name for name in sorted(os.listdir("sales")) if name.endswith(".csv")]
print(len(csv_files))
print(csv_files)
輸出3 ['2026-01.csv', '2026-02.csv', '2026-03.csv']

讀 CSV、合併資料是路線圖第 12、13 站的內容，這裡只示範怎麼拿到檔名。

04

建立資料夾

os.makedirs(名稱, exist_ok=True) 建立資料夾，資料夾已經存在也不會報錯，路徑有好幾層也能一次建好。

os.mkdir() 一次只建一層，而且資料夾已經存在就報錯。寫工具程式時，同一支程式常常要執行很多次，所以 makedirs 加 exist_ok=True 比較常用。

demo.py
import os

os.makedirs("backup", exist_ok=True)
os.makedirs("backup", exist_ok=True)
print(os.path.exists("backup"))

os.makedirs("year/month/day", exist_ok=True)
print(os.listdir("year"))
輸出True ['month']
  • exist_ok=True資料夾已經存在時當作沒事，繼續往下執行。不寫的話預設是 False，會報 FileExistsError。
  • "year/month/day"中間的 year、month 不存在也會一起建出來。這是 mkdir 做不到的。
容易踩的坑
第二次建同名資料夾，os.mkdir() 會停在這一行：
demo.py
import os

os.mkdir("backup")
os.mkdir("backup")
現在跑出來Traceback (most recent call last): File "/Users/你/Desktop/demo.py", line 4, in <module> os.mkdir("backup") FileExistsError: [Errno 17] File exists: 'backup'
上層資料夾不存在時，os.mkdir("year/month") 也會報錯。最後一行是 FileNotFoundError: [Errno 2] No such file or directory: 'year/month'。
05

刪除檔案與資料夾

os.remove() 刪檔案，os.rmdir() 只能刪空資料夾，shutil.rmtree() 連裡面的東西一起刪，三個都不會進資源回收桶或垃圾桶。

shutil 是另一個內建模組，專門處理檔案的複製、移動、整個資料夾的刪除，用法跟 os 一樣，import shutil 之後直接用。

demo.py
import os
import shutil

os.remove("a.txt")
os.rmdir("empty")
shutil.rmtree("full")

print(os.path.exists("a.txt"))
print(os.path.exists("empty"))
print(os.path.exists("full"))
輸出False False False
  • os.remove(檔名)刪一個檔案。對資料夾使用會報錯。
  • os.rmdir(名稱)刪一個資料夾，裡面必須是空的。
  • shutil.rmtree(名稱)刪掉整個資料夾，包含裡面所有的檔案和子資料夾。
容易踩的坑
rmdir 碰到有東西的資料夾會停下來：
demo.py
import os

os.rmdir("full")
現在跑出來Traceback (most recent call last): File "/Users/你/Desktop/demo.py", line 3, in <module> os.rmdir("full") OSError: [Errno 66] Directory not empty: 'full'
這是 Mac 上的訊息，Windows 上的文字不同，但同樣是 OSError。刪一個不存在的檔案，os.remove() 的最後一行是 FileNotFoundError: [Errno 2] No such file or directory: 'a.txt'。
三個函式刪掉就沒有了。rmtree 刪錯資料夾救不回來，執行之前先 print(os.listdir(路徑)) 看一眼。
動手試
先建一個 box 資料夾，用 shutil.copy 放一個檔案進去（單元 07），用 os.rmdir("box") 看會出什麼錯，再改用 shutil.rmtree("box")。
06

改名與搬移

os.rename(舊名, 新名) 把檔案或資料夾改名，新名字帶著資料夾路徑，就等於搬到那個資料夾。

demo.py
import os

os.rename("b.txt", "note_01.txt")
os.rename("c.py", os.path.join("backup", "c.py"))

print(sorted(os.listdir(".")))
print(os.listdir("backup"))
輸出['backup', 'note_01.txt'] ['c.py']
  • 第一行b.txt 改名成 note_01.txt，還在原來的資料夾。
  • 第二行新名字是 backup/c.py，所以 c.py 從目前資料夾搬進 backup。
容易踩的坑
新名字已經有同名檔案時，Mac 上 os.rename() 不會問你，直接覆蓋。下面 a.txt 有 2 個位元組，b.txt 有 5 個，改名之後只剩一個 b.txt，大小是 2，原本的 b.txt 已經不見了：
demo.py
import os

os.rename("a.txt", "b.txt")

print(os.listdir("."))
print(os.path.getsize("b.txt"))
輸出['b.txt'] 2
Python 官方文件說 Windows 上遇到同名會報 FileExistsError，我沒有在 Windows 上實測。兩個系統行為不同，所以改名之前先用 os.path.exists(新名字) 檢查（單元 08）。
舊名字不存在時，最後一行是 FileNotFoundError: [Errno 2] No such file or directory: 'nothere.txt' -> 'x.txt'。
之後能拿來做什麼
小工具資料夾裡有一百張 IMG_0001.jpg 這種相機檔名，用 listdir 加 rename 一次改成有意義的名字，這是小專案要做的事。
07

複製檔案與組合路徑

shutil.copy(來源, 目標) 複製檔案，目標寫資料夾就沿用原檔名，目標寫成「資料夾加檔名」就改用新檔名。

路徑要用 os.path.join() 接，不要自己用 + 加斜線。它會依照目前的作業系統選對分隔符號。

demo.py
import os
import shutil

shutil.copy("c.py", "backup")
shutil.copy("c.py", os.path.join("backup", "copy_of_c.py"))

print(sorted(os.listdir("backup")))
print(os.path.join("backup", "copy_of_c.py"))
輸出['c.py', 'copy_of_c.py'] backup/copy_of_c.py
  • 第一行目標 "backup" 是資料夾，複製出來的檔案叫 c.py。
  • 第二行目標是 backup/copy_of_c.py，複製出來的檔案改名叫 copy_of_c.py。
  • os.path.join()把好幾段接成一條路徑。Mac 印出來是 backup/copy_of_c.py，Windows 會是 backup\copy_of_c.py。
底下發生什麼事（想深入再點開）

兩個系統用不同的符號隔開路徑裡的資料夾。os.sep 存的就是目前系統的那個符號，os.path.join() 用的是它。在 Mac 上：

demo.py
import os

print(os.sep)
輸出/

Python 官方文件寫明 Windows 上 os.sep 是反斜線。自己寫 "backup" + "/" + "c.py"，換到另一個系統就要改，用 join 不用改。

容易踩的坑
目標資料夾不存在時，shutil.copy() 不會幫你建，最後一行是 FileNotFoundError: [Errno 2] No such file or directory: 'nodir/c.py'。先用 os.makedirs(..., exist_ok=True) 建好再複製。
目標已經有同名檔案，它直接覆蓋，沒有任何提示。c.py 有 5 個位元組，backup/c.py 原本只有 1 個，複製之後 backup/c.py 的大小是：
demo.py
import os
import shutil

shutil.copy("c.py", "backup")
print(os.path.getsize(os.path.join("backup", "c.py")))
輸出5
之後能拿來做什麼
小工具每天把重要的檔案複製進 backup 資料夾，名字前面加上日期，這是練習 7 要寫的。

08

先檢查再動手：巢狀 if

動檔案之前先用 os.path.exists 問一次，if 裡面可以再放 if，縮排多一層，就是多一個前提條件。

下面的程式要確認 backup 這個名字可以拿來當資料夾。它有三種情況：名字不存在就建立；存在而且是資料夾，什麼都不用做；存在但是個檔案，就不能建立。這三種情況分兩層判斷，第一層問存不存在，第二層才問是檔案還是資料夾。

demo.py
import os

folder = "backup"

if os.path.exists(folder):
    if os.path.isdir(folder):
        print(folder + " 已經是資料夾")
    else:
        print(folder + " 是檔案，不能拿來當資料夾")
else:
    os.mkdir(folder)
    print("建立 " + folder)
輸出backup 不存在 → 建立 backup backup 是資料夾 → backup 已經是資料夾 backup 是檔案 → backup 是檔案，不能拿來當資料夾
  • 縮排內層的 if 往右縮一層，表示外層條件成立才會走到這裡。
  • else 配對else 跟縮排相同的那個 if 配成一對。內層的 else 屬於 isdir，外層的 else 屬於 exists。

課堂檔案 8-28.py 就是這個結構，外面多包了一層。把它的判斷畫成樹狀圖，從上往下讀，縮排一樣深的是同一層的兩條路：

8-28.py 的流程（只畫結構，不含程式）
copyfile.txt 存在嗎？
├─ 存在
│   ├─ 刪掉 copyfile.txt
│   └─ myDir 不存在嗎？
│       ├─ 是 → 建立 myDir
│       └─ 否 → 印出 myDir is exist
└─ 不存在
    └─ myDir 存在嗎？
        ├─ 是 → 刪除 myDir
        └─ 否 → 用 os.system 建 dir2、複製、用記事本打開
容易踩的坑
8-28.py 有一個容易看漏的地方：第一個 if 檢查的是目前資料夾的 copyfile.txt，最後一段卻把檔案複製進 dir2 裡面。所以不管重跑幾次，目前資料夾都沒有 copyfile.txt，每次都走「不存在」那條路，myDir 也不會被建立。檢查的位置跟動作的位置要寫成同一個，不然檢查永遠對不上。
之後能拿來做什麼
小工具批次改名之前，先檢查新名字是不是已經有檔案占用，有的話跳過，避免單元 06 的覆蓋，小專案會用到。

09

os.system：把一行指令交給系統

os.system("指令") 把字串原樣交給系統的指令列執行，等指令跑完才繼續，回傳 0 表示成功，不是 0 表示失敗。

在終端機（Windows 叫命令提示字元）手動打的指令，都可以放進 os.system()。指令是哪個系統的，就只能在那個系統上執行。下面是在 Mac 上跑的結果：echo 兩個系統都有，cls 是 Windows 清畫面的指令，Mac 沒有。

demo.py
import os

code = os.system("echo hello")
print(code)

code = os.system("cls")
print(code)
輸出hello 0 sh: cls: command not found 32512

  • print(code)指令失敗之後程式沒有停下來，這行照樣執行。os.system() 不會把失敗變成錯誤訊息。

兩個系統都能跑：shutil 與 platform

複製、改名、刪除用 shutil 和 os 的函式，只有開外部程式非用 os.system() 不可時，才用 platform.system() 判斷系統再選指令。

platform.system() 回傳目前系統的名字：Mac 是 "Darwin"，Windows 是 "Windows"，Linux 是 "Linux"。下面把課堂那種「建資料夾、複製檔案、打開」的流程，改成兩個系統都能執行的寫法。notes.txt 要先放在同一個資料夾。

demo.py
import os
import shutil
import platform

print(platform.system())

os.makedirs("dir2", exist_ok=True)
target = os.path.join(os.getcwd(), "dir2", "copyfile.txt")
shutil.copy("notes.txt", target)
print(os.path.exists(target))

if platform.system() == "Windows":
    os.system('notepad "' + target + '"')
else:
    os.system('open -t "' + target + '"')
輸出Darwin True （接著用文字編輯器打開 dir2/copyfile.txt）
  • makedirs取代 os.system("mkdir dir2")，資料夾已經存在也不會出錯。
  • os.path.join取代手寫 "\dir2\copyfile.txt"，兩個系統都能用。
  • shutil.copy取代 copy 和 cp。
  • if / elseWindows 用 notepad，其他系統用 open -t。我只確認過組出來的指令字串是對的，這個範例沒有開出真的視窗，也沒有在 Windows 上跑過。

程式好像卡住了怎麼辦

下面幾種狀況看起來像程式壞了，但都不是語法寫錯：

跑到 os.system 那一行就不動os.system() 會等指令結束才繼續（單元 09 用 sleep 量過）。指令開的是要手動關掉、或在等你輸入的程式時，Python 就停在那一行。看有沒有視窗或提示在等你；要強制中止，在終端機按 Ctrl + C。Windows 的 notepad 會不會等到視窗關掉，我沒有實測。
程式跑完了，沒有錯誤，但什麼都沒發生exists 回傳 False，走進了沒有動作的分支。最常見的原因是目前工作資料夾不對（單元 01、02）。在程式開頭加 print(os.getcwd()) 和 print(os.listdir("."))，看資料夾裡實際有什麼。
再執行一次，結果跟第一次不一樣程式動過電腦裡的檔案：第一次執行刪掉、建立或改名了東西，第二次執行時檔案已經不在原本的狀態。重跑之前把檔案復原，或用 exist_ok=True（單元 04）、先檢查再動手（單元 08）讓程式重複執行也沒問題。

怎麼讀錯誤訊息

錯誤訊息照這三步讀。下面是 os.remove("a.txt") 刪除一個不存在的檔案的結果：

實際的錯誤訊息
Traceback (most recent call last):
  File "/Users/你/Desktop/remove.py", line 3, in <module>
    os.remove("a.txt")
FileNotFoundError: [Errno 2] No such file or directory: 'a.txt'
  • 先看最後一行那是結論。FileNotFoundError 是找不到檔案，後面寫出是哪個名字：'a.txt'。
  • 再看 line NFile 那一行最後的 line 3 直接告訴你第 3 行出事。跳過去看那一行，再往上找 a.txt 是從哪裡來的。
  • 中間可以跳過Traceback、檔案路徑先不用讀。用到 shutil 的錯誤會多出好幾段 shutil.py 的內容（單元 07），一樣只看最後一行。

看到這些錯誤代表什麼

FileNotFoundError找不到檔案或資料夾：名字拼錯、目前工作資料夾不對，或是上層資料夾不存在。
FileExistsError已經有同名的東西：對已存在的資料夾用 os.mkdir()。
OSError資料夾不是空的（Directory not empty）：對有東西的資料夾用 os.rmdir()。
PermissionError沒有權限：PermissionError: [Errno 13] Permission denied: 'locked/new'。在唯讀的資料夾裡建立東西會出現。
NotADirectoryError拿檔案當資料夾用：NotADirectoryError: [Errno 20] Not a directory: 'a.txt'。

檔案清單與批次改名

相機或手機匯出的檔案常常是一長串看不懂的編號，這個小程式先列出資料夾裡有什麼，再一次把符合條件的檔案改成有規則的名字。一步一步來，每一步都先跑得起來再做下一步：

00先執行下面的準備程式，建出練習用的 rename_demo 資料夾，裡面有三個 IMG_ 開頭的 .txt、一個 readme.md、一個叫 old 的資料夾。
01印出 rename_demo 裡所有的名字，按順序排好，每個名字後面標「（檔案）」或「（資料夾）」。
02只留副檔名是 .txt 的，每個名字前面加編號，編號從 1 開始。
03照排好的順序，印出每個 .txt 的「舊名 → 新名」預覽，新名字是 note_01.txt、note_02.txt……，這一步先不真的改名。
04預覽沒問題之後，用 os.rename() 真的改。如果新名字已經有檔案，就印「跳過 … 已經存在」，不要覆蓋。
05改完再印一次整個資料夾的內容，確認結果。
setup.py
import os

os.makedirs("rename_demo/old", exist_ok=True)
for name in ["IMG_0003.txt", "IMG_0001.txt", "IMG_0002.txt", "readme.md"]:
    open(os.path.join("rename_demo", name), "w").close()

準備程式裡的 open(檔名, "w").close() 會建立一個空檔案。open() 讀寫檔案內容在課堂後面才教，這裡先照打。

提示
os.listdir() 回傳的只有名字，開檔、判斷、改名都要先用 os.path.join(folder, name) 接成路徑。
補零寫成 "note_%02d.txt" % i。%02d 補的是 0，串列（三）教的 %2d 補的是空格。enumerate(串列, 1) 讓編號從 1 開始。
先只 print 預覽，順序對了再接 os.rename()。改名遇到同名檔案會直接覆蓋（單元 06），所以要先用 os.path.exists() 檢查（單元 08）。
