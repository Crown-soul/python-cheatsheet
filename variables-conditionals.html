要背的只有這幾個，其他都用查的

9 個單元裡，沒背起來就打不出第一行的是這四個形狀。其他都是要用的時候回來查。

01一個等號存，兩個等號問
x = 5              # 把 5 存進 x
if ( x == 5 ):     # 問 x 是不是 5

這是初學最常錯的一個。= 是動作，== 是問句。

02問使用者拿資料
k = int( input( "請輸入數字：" ) )

input() 拿到的永遠是字串，要算數學一定要包一層 int() 或 float()。整組一起背，不要拆開記。

03判斷的形狀
if ( 條件 ):
    做事
elif ( 另一個條件 ):
    做別的
else:
    都不成立時做這個

由上往下一路問，第一個成立的就執行，剩下的全部跳過。冒號跟縮排跟迴圈一樣不能少。

04把結果講清楚
print( f"{name} 的分數是 {score}" )

引號前面加一個 f，變數直接寫進大括號。不管是文字還是數字都能印，不會報錯。

這些放心去查，不用背
f-string 的格式語法（:.2f 這種）、%d / %s 怎麼對應、and 跟 or 的優先順序、各種錯誤訊息代表什麼。附錄都查得到。
自我測試
關掉這一頁，空白檔案打得出「問使用者一個數字，判斷是不是大於 60，印出結果」這段，就可以往下讀了。
CH 1 · 把資料存起來
01

變數是什麼

變數就是「幫一份資料取個名字」，之後叫名字就能拿到它。

寫 a = 1 的意思不是「a 等於 1」，而是「把 1 放進一個叫 a 的盒子裡」。等號右邊先算完，結果才存到左邊。同一個盒子可以重新放東西，新的值會蓋掉舊的。

1-1.py 
a = 1
b = 2
c = a + 1

print( a, b, c )
輸出 1 2 2
  • c = a + 1先算 a + 1（結果是 2），再把 2 存進 c。
  • print(...)逗號分隔的多個值印在同一行，中間會空一格。
動手試
把 a = 1 改成 a = 10，先猜 c 會印出多少，再執行看看。
02

常數是一種約定

Python 沒有常數這種語法，全大寫的變數名稱是在提醒「這個值別改」。

像稅率、滿分這類寫死的數字，習慣上用全大寫命名。程式改得動，但看到全大寫，自己和同組的人就知道不要動它。

參考範例 
# 全大寫 = 慣例上的常數，不要去改它
TAX_RATE = 0.05
MAX_SCORE = 100

price = 500
print( price * (1 + TAX_RATE) )
輸出 525.0
03

命名規則：四條就夠

01 只能用英文字母、數字、底線，而且不能用數字開頭。
02 大小寫算不同的變數：name 和 Name 是兩個盒子。
03 不能用保留字，例如 if、for、class。編輯器會把它們標成特別的顏色，看到變色就換名字。
04 Python 習慣用蛇式命名：全小寫、底線連接，例如 student_name。
參考範例 
student_name = "小美"
Student_Name = "阿明"

print( student_name )
print( Student_Name )

# 3name = "錯誤示範"   -> SyntaxError，不能用數字開頭
# if = 10              -> SyntaxError，if 是保留字
CH 2 · 讓程式做選擇
04

一個等號和兩個等號

= 是動作（存進去），== 是問句（一樣嗎）。

=
賦值：把右邊存進左邊
執行完不會回答問題，只負責把值放好。
a = 100
==
比較：問左右是否相等
答案只有 True 或 False，所以才能放在 if 後面。
a == 100 → True
範例 
a = 100

if int(a) == 100:
    print("good !")
輸出 good !
容易踩的坑
在 if 後面只打一個 =，Python 會報 SyntaxError。看到 SyntaxError 先回去數等號有幾個。
05

input() 回傳的永遠是字串

input() 收到的一定是字串，要算數學就先用 int() 或 float() 轉過去。

就算你輸入 100，Python 拿到的是「文字的 100」。文字不能跟數字做加減乘除，所以要先轉型。整數用 int()，有小數用 float()。

1-1.py 
c = 2

d = input( "pls enter:" )   # d 是字串
print( d )

DD = int( d )              # 轉成整數才能相加
e = c + DD

print( e )
輸出 輸入 8 → 印出 8，再印出 10
容易踩的坑
忘記轉型 → TypeError；輸入了「八」或空白再 int() → ValueError。兩種錯誤都在講同一件事：型別沒對上。
06

if / elif / else

由上往下一路問，第一個成立的就執行，剩下的全部跳過。

if第一個問題。成立就做，做完整段結束。
elif上面都不成立時才問我。可以接很多個。
else以上全部不成立的收尾，不用寫條件。
untitled0.py · 成績分級 
a = input("plz enter")
print(a)

if int(a) == 100:
    print("SooooooooooGoooooooood")
elif int(a) >= 80:
    print("GoooooooD Job")
elif int(a) >= 60:
    print("Nice")
else:
    print("what???")
輸出 輸入 100 → 印出 100，再印出 SooooooooooGoooooooood 輸入 85 → 印出 85，再印出 GoooooooD Job 輸入 30 → 印出 30，再印出 what???
容易踩的坑
條件要由嚴到寬排（100 → 80 → 60）。如果把 >= 60 放在最前面，95 分也會先掉進 Nice，後面的條件永遠檢查不到。還有：冒號和下一行的縮排四格不能少。
07

and 與 or

and 是「兩個都要」，or 是「有一個就好」。

參考範例 
score = int(input("分數："))
attend = int(input("出席次數："))

# and：及格「而且」出席達標，兩個都要成立
if score >= 60 and attend >= 10:
    print("通過")

# or：分數很高「或者」全勤，有一個成立就好
if score >= 90 or attend >= 15:
    print("加分認定")

這裡寫成兩段獨立的 if，而不是 if / elif，因為 elif 只會有一個成立；通過和加分要能同時發生，得各自判斷。

CH 3 · 把結果講清楚
08

字串和數字不能直接相加

同一個 + 號，遇到數字是加法，遇到字串是接起來，混在一起就報錯。

三種情況 
print( 1 + 2 )        # 3　　　數字加數字
print( "1" + "2" )    # "12"　字串接字串
print( "1" + 2 )      # TypeError　混在一起會報錯
處理原則
要顯示在畫面上 → 全部轉成字串（或用下一個單元的 f-string）；要做數學計算 → 全部轉成數字。
09

f-string：最推薦的組字串方式

字串前面加一個 f，變數直接寫進 {}，不管是什麼型別都能印出來。

課堂上示範的是舊式的 %s / %d 寫法：要記哪個佔位符配哪種型別，還要照順序放。兩種都看得懂就好，自己寫用 f-string。

2-3-0.py · 舊式寫法 
A1 = "apollo"
A2 = "ava"
a2 = 99

print( "%s %s 好 %d" % (A1, A2, a2) )
改寫版本 · f-string（推薦） 
print( f"{A1} {A2} 好 {a2}" )
輸出 apollo ava 好 99
容易踩的坑
f-string 不會幫你檢查型別對不對——忘記把 input() 轉型，f"{age}" 照樣印得出來，不會報錯；換成舊式的 %d 反而會直接噴 TypeError，等於幫你抓到忘記轉型這件事。
小數也不會自動幫你捨去，f"{0.1 + 0.2}" 會印出 0.30000000000000004，這是電腦存小數本來就有的誤差。想要顯示乾淨一點，可以寫 f"{值:.2f}" 指定小數位數。
動手試
用 input() 問名字和分數，再用一行 f-string 印出「小美 的分數是 90」。
附錄

看到這些錯誤代表什麼

SyntaxError語法寫錯：漏冒號、漏括號、if 後面只打一個 =。
TypeError型別不合：字串和數字直接相加。
ValueError型別對但內容不能轉：int("八")。
NameError用到還沒定義的變數，或名字打錯字、大小寫不一致。
IndentationError縮排不對：if 下一行忘了縮進去，或空格數不一致。

練習題

前六題各自對應前面一個單元，寫完再往下一題。最後一題把整份筆記的東西兜在一起，是這份筆記的大魔王題。

練習 1

變數與 print

設三個變數 x = 5、y = 3、z = x + y，用一行 print() 把 x、y、z 都印出來。

參考解答（先自己寫，再點開對照）
1.py
x = 5
y = 3
z = x + y

print(x, y, z)
輸出5 3 8

print() 裡用逗號隔開，印出來時每個值中間會補一個空格。

練習 2

常數命名

一杯咖啡原價 60 元，稅率固定 5%。用一個全大寫的變數存稅率，算出含稅價格並印出來。

參考解答（先自己寫，再點開對照）
2.py
TAX_RATE = 0.05
price = 60

print(price * (1 + TAX_RATE))
輸出63.0

含稅價是原價乘上 (1 + TAX_RATE)。寫成 (1 - TAX_RATE) 會得到 57.0，程式照樣跑得動，所以要拿 63.0 對答案。

練習 3

輸入與轉型

用 input() 問一個數字，轉成整數後判斷是不是等於 100，符合就印出「猜中了」。

參考解答（先自己寫，再點開對照）
3.py
guess = int(input("請輸入一個數字："))

if guess == 100:
    print("猜中了")
輸出輸入 100 → 猜中了
輸入 99 → 什麼都不印

input() 回傳的是字串，字串 "100" 跟數字 100 用 == 比永遠是 False，所以一定要先用 int() 轉型。

練習 4

if / elif / else 分級

用 input() 問分數，90 以上印「優」，80 以上印「甲」，70 以上印「乙」，60 以上印「丙」，其他印「丁」。留意判斷順序。

參考解答（先自己寫，再點開對照）
4.py
score = int(input("請輸入分數："))

if score >= 90:
    print("優")
elif score >= 80:
    print("甲")
elif score >= 70:
    print("乙")
elif score >= 60:
    print("丙")
else:
    print("丁")
輸出95 → 優
90 → 優
89 → 甲
80 → 甲
79 → 乙
70 → 乙
65 → 丙
60 → 丙
59 → 丁

從分數最高的門檻開始問。elif 只在上面都不成立時才會被問到，順序倒過來的話，95 分會先符合 score >= 60，印出「丙」。

練習 5

and / or 組合條件

問身高（公分）和體重（公斤）。身高 >= 160 而且體重 >= 50，印「符合標準」；身高 >= 180 或者體重 >= 90，另外印「體型較大」。這兩個結果可能同時出現。

參考解答（先自己寫，再點開對照）
5.py
height = int(input("請輸入身高（公分）："))
weight = int(input("請輸入體重（公斤）："))

if height >= 160 and weight >= 50:
    print("符合標準")

if height >= 180 or weight >= 90:
    print("體型較大")
輸出身高 170、體重 60 → 符合標準
身高 175、體重 90 → 符合標準、體型較大
身高 185、體重 45 → 體型較大
身高 159、體重 50 → 什麼都不印

兩個結果可以同時成立，所以拆成兩個獨立的 if。用 elif 串起來的話，第一個成立後第二個就不會被問，身高 175、體重 90 的人會漏掉「體型較大」。

f-string 組字串

問姓名和年齡（年齡記得轉型），用一行 f-string 印出「OOO 今年 XX 歲」。

大魔王

期末成績小系統

寫一個小工具，一次用到這份筆記教的每一件事：

01 用 input() 問學生姓名，再問段考分數（記得轉型）。
02 分數對應等第：90 以上「優」，80 以上「甲」，70 以上「乙」，60 以上「丙」，其他「丁」。
03 再用 input() 問出席次數（記得轉型）。
04 分數 >= 85 的人，或是「分數 >= 70 而且出席次數 >= 15」的人，都要額外印出「符合獎學金申請資格」。
05 最後用一行 f-string 印出：「OOO 的段考成績是 XX 分，等第是 OO」。
大魔王提示
elif 的判斷順序要顧好，順序排錯的話，95 分可能會先掉進「乙」。
第 4 點的「符合資格」不是等第判斷的一部分，是另一個獨立的 if，因為它跟任何等第都可能同時成立。
兩次 input() 拿到的都是字串，姓名不用轉，分數和出席次數要轉。
最後那句只需要一行 f-string，變數直接放進 {} 就好，不用再用 + 拼字串。
參考解答（先自己寫，再點開對照）
boss.py
student_name = input("請輸入學生姓名：")
score = int(input("請輸入段考分數："))
attendance = int(input("請輸入出席次數："))

if score >= 90:
    grade = "優"
elif score >= 80:
    grade = "甲"
elif score >= 70:
    grade = "乙"
elif score >= 60:
    grade = "丙"
else:
    grade = "丁"

if score >= 85 or (score >= 70 and attendance >= 15):
    print("符合獎學金申請資格")

print(f"{student_name} 的段考成績是 {score} 分，等第是 {grade}")
輸出王小明、95 分、出席 5 → 符合獎學金申請資格 ＋ 王小明 的段考成績是 95 分，等第是 優
李小華、72 分、出席 10 → 李小華 的段考成績是 72 分，等第是 乙
李小華、72 分、出席 15 → 符合獎學金申請資格 ＋ 李小華 的段考成績是 72 分，等第是 乙
陳大文、69 分、出席 20 → 陳大文 的段考成績是 69 分，等第是 丙
張三、84 分、出席 15 → 符合獎學金申請資格 ＋ 張三 的段考成績是 84 分，等第是 甲
張三、70 分、出席 14 → 張三 的段考成績是 70 分，等第是 乙

等第用 if / elif / else 決定，只有一個結果；獎學金資格是另一個獨立的 if，所以跟等第各寫各的。or 跟 and 混用，括號一定要加。
